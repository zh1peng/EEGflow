# Surface Resources

This folder contains surface mesh files used by EEGflow's `+rest` plotting utilities.

## Included files

### `surface_white_both.mat`

Cortical surface mesh (both hemispheres) in a FieldTrip-readable format. This is typically used for "glass brain" plots and for mapping ROI values onto a cortical surface.

**Attribution / origin**

This file is copied from the FieldTrip template anatomy surfaces (`template/anatomy/`).
