# Atlas Resources

This folder contains atlas centroid CSV files used by EEGflow's `+rest` module.

## Included files

### `Schaefer2018_100Parcels_7Networks_order_FSLMNI152_1mm.Centroid_RAS.csv`

Centroid coordinates (MNI RAS, mm) for the Schaefer2018 atlas (100 parcels, 7 networks).
